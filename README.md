# Depths Master Emulator (DMEmu)

Solo / GM emulator module for the [Fantastic Depths](https://github.com/Forelius/fantastic-depths) Foundry VTT system (v13–v14).

## Credits

Inspired by **Game Unfolding Machine** by JeansenVaars. DMEmu adapts and extends that approach for Fantastic Depths; it is not an official GUM product.

## Status

Early scaffold (`0.1.0`). See `../docs/dmemu-plan.md` in the workspace for the implementation plan.
